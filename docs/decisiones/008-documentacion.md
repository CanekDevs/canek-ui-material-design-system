# 008. Sitio de documentación + Storybook

- Estado: Aceptada
- Fecha: 2026-11-17

## Contexto

La meta es un sitio con todo el contexto del framework, al estilo de m3.material.io o astryx.atmeta.com.

## Decisión

Un sitio de documentación propio, generado desde este repo, con: fundamentos (color, tipografía, forma, elevación, movimiento, espaciado), reglas, decisiones, fichas por componente con ejemplos vivos del paquete real y código para copiar, y guía de migración. Storybook se mantiene como laboratorio de desarrollo y pruebas, enlazado desde el sitio.

## Consecuencias

- Cada componente terminado necesita su ficha en el sitio.
- La tecnología y el hospedaje del sitio se deciden en un ADR posterior.
